# 🎮 ПРОТОКОЛ-6 — кооперативный 3D-шутер в симуляции

Вас и ваш отряд (до **6 бойцов**) отправляют в боевую симуляцию: удерживайте неоновый полигон против волн зомби, чертей-бегунов, плеваков, брутов и босса **Разрушителя**. В духе Doom / Left 4 Dead, но с классами, способностями и голосовым чатом.

## ▶️ Запуск
```bash
npm install
npm run dev    # http://localhost:5173
npm run build  # продакшн-сборка в dist/
```

## 🕹️ Что внутри
- **Лобби до 6 игроков**: код комнаты (создать / войти по коду), слоты отряда, готовность, пинг, добор ИИ-бойцами. ИИ-союзники реально сражаются рядом с вами в 3D, у каждого — свой класс, имя и полоса HP.
- **4 класса и персонажа**:
  - 🔫 **Штурмовик Рекс** — винтовка, способность «Стим» (темп + скорость)
  - 💉 **Медик Мила** — быстрый ПП, пассивная регенерация, «Мед-нова» лечит отряд
  - 💪 **Тяжёлый Гром** — дробовик ×8, 210 HP, «Энергощит»
  - 🎯 **Разведчик Призрак** — ДМР с огромным уроном в голову, «Рывок»
- **Уровень 01 «Неоновый полигон»** (уровни 02–03 — в планах): порталы спауна, укрытия, парящие кубы симуляции.
- **Враги**: 🧟 зомби, 👺 черти-бегуны, 🟣 плеваки (дальний бой), 🦍 бруты, ☠ босс **Разрушитель** каждую 5-ю волну (рывки, призыв миньонов, полоса HP босса).
- **🎙️ Микрофон и голос**:
  - Реальный доступ к микрофону (`getUserMedia`) + живой индикатор уровня и «в эфире»
  - Push-to-Talk на **V** или открытый микрофон, мьют на **M**, 🎤-кнопка на телефоне
  - **Голосовые команды** (Web Speech API, ru-RU): «граната!», «лечи!», «перезарядка!», «огонь!»
  - Голосовой лог отряда и реплики союзников в лобби и в бою
- **Сочность**: тряска экрана, частицы, трассеры, вспышка выстрела, отдача, хитмаркер, всплывающий урон, криты в голову, взрывы гранат с ударной волной, виньетка урона/лечения, баннеры волн, серия убийств ×combo.
- **Системы**: счёт и множитель серии, волны с бонусами, подборы (аптечки/гранаты/щит), пауза, экран поражения со статистикой (точность, хедшоты), **локальная таблица рекордов** (localStorage, топ-10), мгновенный рестарт по **R**.
- **Управление**: WASD + мышь (pointer lock), Shift — спринт, Space — прыжок, Q — способность, G — граната, R — перезарядка, P/Esc — пауза. На мобильных: виртуальный стик, свайп-обзор, кнопки ОГОНЬ/ПРЫГ/Q/R/🎤.
- **Производительность**: пул частиц на одном `THREE.Points`, пул трассеров, кап врагов на экране, без теней — стабильные 60 FPS на десктопе и мобильных.
