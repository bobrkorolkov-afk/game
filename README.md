# 🏁 RALLY DUO 3D — водитель + штурман

3D-ралли в браузере (Three.js, low-poly «RTX»: тени, bloom, ACES-тонемаппинг).
Один игрок рулит, второй читает стенограмму — как в настоящем раллийном экипаже.

## Возможности

- **Онлайн-лобби**: комнаты по 4-значному коду или из списка открытых, до **3 команд × 2 человека** (водитель + штурман), чат, готовность, настройки хоста.
- **Голосовой чат по микрофону** (WebRTC mesh): push-to-talk на `V` или открытый микрофон, канал «только команда» / «все», индикаторы речи, мьют игроков. Нет штурмана-водителя? Рулит ИИ.
- **Соло-режим**: вы водитель (ИИ-штурман читает стенограмму голосом через TTS) или вы штурман (ИИ-водитель едет тем увереннее, чем точнее ваши вызовы поворотов).
- **3 процедурные трассы** (лес, горный серпантин, пустыня) со сгенерированной стенограммой: «Правый четыре, через горб, 80, левый три — не резать!».
- **Погода и время суток**: ясно, облачно, дождь, гроза с молниями, снег, туман; сцепление, видимость, фары ночью — всё влияет на езду.
- **Аркадная физика**: дрифт на ручнике, прыжки с трамплинов, повреждения, ремонт на КП, столкновения.
- **Очки стиля**: дрифт-комбо ×5, прыжки, «впритирку», чистые сектора, точные вызовы штурмана. Локальная таблица рекордов, дельты по секторам.
- **60 FPS**: инстансинг тысяч объектов, пресеты качества от «Картошка» до Ultra «RTX».
- **Управление**: клавиатура, геймпад, сенсорные кнопки на телефоне (газ/тормоз/ручник/PTT).

## Запуск

```bash
npm install
npm run build   # сборка клиента в dist/
npm start       # сервер игры+лобби: http://localhost:3000
```

Для разработки:

```bash
npm run dev     # Vite на :5173 (проксирует /ws на сервер лобби :3001)
```

> Для микрофона браузер требует HTTPS или localhost. На продакшене ставьте за reverse-proxy с TLS (Caddy/nginx), WebRTC использует публичные STUN.

## Управление

| Клавиши | Действие |
|---|---|
| `W A S D` / стрелки | газ, руль, тормоз |
| `Пробел` | ручник (дрифт) / у штурмана — объявить поворот |
| `V` (удерживать) | говорить в микрофон |
| `1`–`6` (штурман) | быстрые команды: «Газ!», «Тормози!»… |
| `C` / `H` | камера / клаксон |
| `Backspace` | вернуть машину на трассу (+5 c) |
| `Esc` / `P`, `R` | пауза, рестарт |

Ссылка-приглашение в лобби: `https://ваш-домен/?room=КОД`.
